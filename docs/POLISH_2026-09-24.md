# Dialog, chart and logo polish (alpha.40)

Trent requested a polish audit after using alpha.39: brighter outlines on dialog
close buttons, movable About and other dialogs, easier Lines / Bars switching,
End task higher in the inspector, and readable logo colors during random themes.
The supplied six-second video was sampled at one frame per second; reviewed
frames show the generated T almost disappearing into several dark palettes.

## Changes

- About, Theme Studio, Export, Run task, End task, Priority, Affinity and process/
  service confirmations now share dialog chrome. Windows start centered, can be
  dragged by their header, retain their position on reopening and stay within
  the app viewport. The custom X has a larger glyph, a 28-point target, an opaque
  face and a 1.5-point contrast-corrected outline on hover, press and focus.
  A two-color header rule and small grip follow the active theme. Closing a
  confirmation cancels it. These are egui windows inside Trontop, not additional
  native desktop windows; no OS dragging-performance claim is made.
- Lines / Bars now lives in the command bar on Overview, Graphs, Performance and
  Hardware sensors. One choice controls their history plots and the smaller
  history bands. It is stored in existing UI memory, separately from exported
  themes. Gaps remain gaps; measured zero samples get a one-pixel baseline.
  Rank bars and the current core-usage strip keep their existing meaning.
- Inspector identity and End task stay above the scrolling details. End task
  still stages the original process identity for confirmation; it does not
  directly terminate a process. Run task focuses the command field once on open
  so keyboard focus can leave an empty field.
- The generated logo's gradient is corrected against the theme's surface
  brightness envelope before coloring its alpha mask. Dark palettes lift and
  pale palettes darken as needed for the current light/dark mode. The source PNG,
  theme colors, transparency and interior cuts remain unchanged. A cached
  512-color ramp avoids per-pixel contrast searches on every frame. Native icon
  updates now also include mode changes; the animated tray graph stays as-is.

- `cargo clippy --offline --all-targets -- -D warnings`: PASS.
- `cargo build --release --offline`: PASS; verified alpha.40 is installed and

- `render_polish_visual_pass`: PASS; all 16 PNGs under
  `target/ui-smoke/polish-alpha40` inspected. Includes dark/light close hover,
  Theme Studio, Export, Run task, process/service dialogs, Overview lines/bars,
  pinned inspector controls and 28 palette samples at 64/32/20-point logo sizes.
- Local egui regressions exercise ten dialog cases with real header drags,
  close/reopen position retention, keyboard X activation, hover-outline contrast,
  shared chart choice and serialized-memory restoration, chart gaps, and pinned
  End task after deep scrolling with an injected backend proving no submission
  before confirmation. Logo tests cover 96 randomized/extreme mode/palette cases.

All UI tests and captures use synthetic fixtures, without native windows, OS input
or process/service commands. Build identity and deployment are recorded separately
in `CURRENT_STATE.md`. This bounded pass does not clear the wider native drag,
provider, close/recovery or soak gates.
