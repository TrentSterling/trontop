# Privacy

Trontop collects system and process information locally to display it. It has no
account, advertising, analytics service, or telemetry upload.

Settings, themes and bounded local failure records are stored under your Windows
user profile. The portable executable has no external runtime asset directory;
"portable" does not mean it writes its preferences beside the executable.

Exports happen only when requested. Private fields are excluded by default;
review exported files before sharing them. Screenshots can expose process names,
usernames, paths and other information visible in the interface.

About's support report contains build and provider status, not process names,
commands, paths, account/host names, GPU IDs or network addresses.

Opening a website link uses your browser. Publishing an issue or attaching files
to GitHub is your choice and is governed by that service's policies.
